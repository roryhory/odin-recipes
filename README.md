# odin-recipes

This is the first project in The Odin Project course and covers the contents of the [HTML Foundations](https://www.theodinproject.com/lessons/foundations-recipes) course

## Project goal
The goal of this project is to showcase linking pages and images in HTML. This website showcases appropriate use of element hierarchies and folder structures to act as a template that can be added to after future lessons.

The current version only contains HTML pages with no CSS styling, however this will be added in future versions
